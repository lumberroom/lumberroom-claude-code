# Security policy

## Supported versions

The latest release on `main` only. A fix ships as a new version, not a backport.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting, not a public issue:
[github.com/lumberroom/lumberroom-claude-code/security/advisories/new](https://github.com/lumberroom/lumberroom-claude-code/security/advisories/new).
A flaw in the engine itself goes to
[lumberroom/lumberroom](https://github.com/lumberroom/lumberroom/security/advisories/new) instead.

Include:

- the plugin version and the Claude Code version
- steps to reproduce, or a proof of concept
- what an attacker gains: memory read, memory write, a leaked token, or something else

## What to expect

- Acknowledgement within 5 business days.
- The fix gets a line in the changelog once released. Credit is given if you want it and withheld
  if you don't.

No PGP key and no bounty program.
